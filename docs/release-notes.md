## Bounded original-Slot report reread (G5-3B2a3)

The reread starts no worker and reruns no checker; original capture/snapshot/plan/receipt/history/cost are unchanged. Equal duplicate calls share the exact admitted Promise and settled replay.

The call requires the original report reference, full input SHA-256, retained signal and current source/check refs, with fresh host refresh and pure revalidation before admission and before join. Cancel is by exact report ID, and disposal drains report rereads independently of capture, holding reservation until the actual leaf settles and handles close.
